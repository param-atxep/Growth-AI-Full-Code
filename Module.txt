                            1. INTRODUCTION
================================================================================

GrowthPilot AI is a comprehensive retail management platform designed for small
and medium business owners. The application follows a multi-tenant architecture
where each merchant has their own isolated data store.

KEY CONCEPTS:
- User: The merchant who owns the account
- Store: The business entity (each user can have multiple stores)
- Multi-tenant: Each store's data is completely separate from others
- Credits: Virtual currency used for AI features

4.1 AUTHENTICATION MODULE
================================================================================

PURPOSE: Handle user registration, login, and session management

FILES:
  Backend:
    - routes/auth.routes.ts     → API endpoints
    - services/auth.service.ts  → Business logic
    - middlewares/auth.ts       → JWT verification
  
  Frontend:
    - pages/auth/Login.tsx      → Login page
    - pages/auth/Register.tsx   → Registration page
    - store/authStore.ts        → Auth state management

ENDPOINTS:
  POST /api/auth/register
    Input:  { name, email, password, storeName }
    Output: { user, store, tokens: { accessToken, refreshToken } }
    
  POST /api/auth/login
    Input:  { email, password }
    Output: { user, store, tokens: { accessToken, refreshToken } }
    
  POST /api/auth/refresh
    Input:  { refreshToken }
    Output: { accessToken, refreshToken }
    
  POST /api/auth/logout
    Input:  Authorization header with token
    Output: { message: "Logged out successfully" }
    
  GET /api/auth/me
    Input:  Authorization header with token
    Output: { user, store }

WORKFLOW:
  1. User enters email/password
  2. Backend validates credentials
  3. If valid, generate JWT tokens (access + refresh)
  4. Frontend stores tokens in memory/localStorage
  5. All subsequent requests include Authorization header
  6. Middleware validates token on protected routes
  7. Token refresh happens automatically when access token expires

SECURITY:
  - Passwords hashed with bcrypt (12 rounds)
  - Access tokens expire in 7 days
  - Refresh tokens expire in 30 days
  - Tokens contain: userId, email, storeId

ENDPOINTS:

    Query: ?page=1&limit=20&search=&categoryId=&lowStock=false&sortBy=name&sortOrder=asc
    Output: { products: [...], pagination: { page, limit, total, totalPages } }
    
  POST /api/products
    Input: {
      name, sku, barcode?, categoryId?, description?,

      hsnCode?, unit?, stockQuantity?, lowStockThreshold?,

    Output: { product with category }
    
  PUT /api/products/:id
    Input: { ...partial product fields }
    Output: { updated product }
    
  DELETE /api/products/:id
    Output: { message: "Product deleted" }
    
  POST /api/products/:id/stock-adjust
    Input: { type: "add"|"subtract"|"set", quantity, reason? }
    Output: { product, stockMovement }
    
  POST /api/products/bulk-import
    Input: { products: [...] }
    Output: { imported: count, failed: count, errors: [...] }

CATEGORIES:
  GET /api/products/categories
    Output: [{ id, name, description, color, icon, productCount }]
    
  POST /api/products/categories
    Input: { name, description?, color?, icon? }
    Output: { category }
    
  PUT /api/products/categories/:id
    Input: { name?, description?, color?, icon? }
    Output: { category }
    
  DELETE /api/products/categories/:id
    Output: { message: "Category deleted" }

PRODUCT FIELDS EXPLAINED:
  - sku: Stock Keeping Unit (unique identifier)
  - barcode: For barcode scanner integration
  - costPrice: How much you paid for the product
  - sellingPrice: How much you sell it for
  - mrp: Maximum Retail Price
  - gstRate: GST percentage (0%, 5%, 12%, 18%, 28%)
  - hsnCode: Harmonized System Nomenclature code (for GST)
  - unit: pcs, kg, ltr, mtr, etc.
  - stockQuantity: Current stock count
  - lowStockThreshold: Alert when stock goes below this
  - reorderQuantity: Suggested quantity to reorder

4.4 SALES MODULE
================================================================================

PURPOSE: Record sales, manage invoices, and track payments

FILES:
  Backend:
    - routes/sale.routes.ts    → API endpoints
    - services/sale.service.ts → Sale logic
  
  Frontend:
    - pages/sales/NewSale.tsx  → POS interface
    - pages/sales/Sales.tsx    → Sales list

ENDPOINTS:
  GET /api/sales
    Query: ?page=1&limit=20&startDate=&endDate=&customerId=&paymentStatus=&paymentMethod=
    Output: { sales: [...], pagination }
    
  POST /api/sales
    Input: {
      items: [{ productId, quantity, unitPrice?, discount? }],
      customerId?,
      paymentMethod: "CASH"|"CARD"|"UPI"|"BANK_TRANSFER"|"CREDIT"|"MIXED",
      discountAmount?: number,
      discountPercent?: number,
      paidAmount: number,
      notes?
    }
    Output: { sale with items and customer }
    
  GET /api/sales/:id
    Output: { sale with items and customer }
    
  POST /api/sales/:id/cancel
    Output: { sale with status: "CANCELLED", stock restored }
    
  GET /api/sales/summary
    Query: ?startDate=&endDate=
    Output: {
      totalRevenue, totalProfit, totalTax, totalDiscount,
      salesCount, averageOrderValue, averageProfitMargin,
      byPaymentMethod: [{ method, count, total }]
    }
    
  GET /api/sales/report/daily
    Query: ?date=YYYY-MM-DD
    Output: { daily summary similar to /summary }

SALE WORKFLOW:
  1. User adds products to cart (select product, enter quantity)
  2. System calculates:
     - Subtotal = sum of (quantity × unitPrice)
     - Discount = discountAmount OR (subtotal × discountPercent / 100)
     - Tax = sum of GST for each item
     - Total = subtotal - discount + tax
  3. User selects payment method
  4. User enters paid amount
  5. System calculates:
     - Due Amount = total - paidAmount
     - Payment Status = PAID (if due=0) | PARTIAL (if due>0)
  6. On sale creation:
     - Generate invoice number (INV-YYMMDD-XXXX)
     - Deduct stock from inventory
     - Update product.totalSold and lastSoldAt
     - Update customer.totalPurchases and totalVisits
  7. Sale can be cancelled to restore stock

PAYMENT METHODS:
  - CASH: Cash payment
  - CARD: Debit/Credit card
  - UPI: UPI payment (PhonePe, GPay, etc.)
  - BANK_TRANSFER: NEFT/IMPS/RTGS
  - CREDIT: On credit (partial/no payment now)
  - MIXED: Combination of methods

FILES:

    - services/ai.service.ts → Groq AI integration
    - config/index.ts        → API key configuration
  
  Frontend:
    - pages/ai/AIAssistant.tsx → Chat interface

ENDPOINTS:
  POST /api/ai/chat
    Input: {
      message: string (user's question),
      context?: {
        includeInventory?: boolean,
        includeSales?: boolean,
        includeExpenses?: boolean
      }
    }
    Output: {
      response: string (AI's answer),
      tokensUsed: number,
      latencyMs: number,
      creditsUsed: 4,
      remainingCredits: number
    }
    
  GET /api/ai/predictions
    Output: { salesPredictions, restockRecommendations }
    
  GET /api/ai/recommendations
    Output: { marketing, growth, inventory recommendations }

AI FEATURES:
  1. CHAT ASSISTANT (4 credits per query)
     - Ask natural language questions about your business
     - Get insights on sales, inventory, expenses
     - Receive recommendations and advice
     
  2. SALES PREDICTIONS (5 credits)
     - Forecast future sales based on history
     - Identify trends and patterns
     
  3. RESTOCK RECOMMENDATIONS (3 credits)
     - Analyze inventory levels
     - Suggest what to reorder and when
     
  4. MARKETING SUGGESTIONS (4 credits)
     - Product promotion ideas
     - Customer targeting strategies
     
  5. GROWTH INSIGHTS (5 credits)
     - Business growth opportunities
     - Competitive analysis tips

HOW IT WORKS:
  1. User sends a query
  2. Backend gathers business context:
     - Store details
     - Recent sales data
     - Inventory status
     - Expense summary
  3. Context + query sent to Groq AI (Llama 3.1 model)
  4. AI generates response
  5. Credits deducted from store balance
  6. Response sent to frontend

EXAMPLE QUERIES:
  - "How is my business doing today?"
  - "Which products should I restock?"
  - "What were my top selling products this week?"
  - "How can I reduce expenses?"
  - "Give me marketing ideas for slow-moving products"

================================================================================
GETTING STARTED
================================================================================

STEP 1: REGISTER YOUR ACCOUNT
  1. Open the application in your browser
  2. Click "Register" on the login page
  3. Fill in:
     - Your name
     - Email address
     - Password (min 6 characters)
     - Store name
  4. Click "Create Account"
  5. You'll receive 100 FREE AI credits!

STEP 2: SETUP YOUR INVENTORY
  1. Go to "Products" in the sidebar
  2. Click "Add Product"
  3. Enter product details:
     - Product name
     - SKU (unique code)
     - Cost price (what you pay)
     - Selling price (what customer pays)
     - Initial stock quantity
  4. Save the product
  5. Repeat for all your products

STEP 3: CREATE CATEGORIES (Optional)
  1. In Products page, click "Categories"
  2. Add categories like "Electronics", "Clothing", etc.
  3. Assign products to categories

STEP 4: ADD CUSTOMERS (Optional)
  1. When making a sale, you can add new customers
  2. Or go to Sales → Customers
  3. Add customer details (name, phone, etc.)

================================================================================
DAILY OPERATIONS
================================================================================

MAKING A SALE:
  1. Click "New Sale" in the sidebar
  2. Search and add products to cart
  3. Adjust quantity if needed
  4. Select customer (optional)
  5. Choose payment method
  6. Enter amount received
  7. Click "Complete Sale"
  8. Invoice number is generated automatically

CHECKING DASHBOARD:
  1. Dashboard shows today's metrics
  2. See revenue, profit, and sales count
  3. View top selling products
  4. Check low stock alerts
  5. Analyze sales trends in charts

RECORDING EXPENSES:
  1. Go to "Expenses" in sidebar
  2. Click "Add Expense"
  3. Enter expense details:
     - Title (e.g., "Electricity Bill")
     - Amount
     - Category (optional)
     - Payment method
  4. Save the expense

RESTOCKING PRODUCTS:
  1. Go to "Products"
  2. Find the product to restock
  3. Click "Adjust Stock" or edit the product
  4. Add the new stock quantity
  5. Optionally enter reason for adjustment

## 📋 Overview

**GrowthPilot AI** is a comprehensive, production-ready SaaS application designed specifically for retail merchants and small business owners. It combines powerful inventory management, sales tracking, expense monitoring, and AI-powered business insights into a single, intuitive platform.

### 🎯 Key Highlights

| Feature | Description |
|---------|-------------|
| 🏪 **Multi-Tenant** | Complete data isolation for each merchant |
| 🤖 **AI-Powered** | Business insights using Groq's Llama 3.1 model |
| 📊 **Real-Time Analytics** | Beautiful dashboards with actionable metrics |
| 💰 **Credit System** | Fair usage model for AI features |
| 🔐 **Enterprise Security** | JWT auth, rate limiting, encrypted passwords |
| 🇮🇳 **India-Ready** | GST, HSN codes, INR currency support |

## 🚀 Installation

### Prerequisites

- **Node.js** ≥ 18.0.0
- **PostgreSQL** ≥ 14
- **npm** or **yarn**
- **Git**

### Step 1: Clone the Repository

```bash
git clone https://github.com/yourusername/growthpilot-ai.git
cd growthpilot-ai
```

### Step 2: Backend Setup

```bash
# Navigate to backend
cd backend

# Install dependencies
npm install

# Copy environment file
cp .env.example .env
```

**Configure `.env` file:**

```env
# Server
PORT=3000
NODE_ENV=development

# Database (PostgreSQL)
DATABASE_URL="postgresql://postgres:YourPassword@localhost:5432/growthpilot_dev?schema=public"

# JWT Authentication
JWT_SECRET=your-super-secret-jwt-key-minimum-32-characters
JWT_REFRESH_SECRET=your-super-secret-refresh-key-minimum-32-characters
JWT_EXPIRES_IN=7d
JWT_REFRESH_EXPIRES_IN=30d

# AI Provider (Groq - Free Tier Available)
GROQ_API_KEY=gsk_your_groq_api_key_here

# Email (Optional - for password reset)
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=your-email@gmail.com
SMTP_PASS=your-app-password
```

```bash
# Generate Prisma client
npm run prisma:generate

# Run database migrations
npm run prisma:migrate

# Start development server
npm run dev
```

### Step 3: Frontend Setup

```bash
# Navigate to frontend (from project root)
cd frontend

# Install dependencies
npm install

# Start development server
npm run dev
```

### Step 4: Access the Application

| Service | URL |
|---------|-----|
| **Frontend** | http://localhost:5173 |
| **Backend API** | http://localhost:3000 |
| **API Health** | http://localhost:3000/api/health |
| **Prisma Studio** | Run `npm run prisma:studio` → http://localhost:5555 |
